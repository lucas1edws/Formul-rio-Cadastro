# Formulário de Cadastro

Projeto de formulário de cadastro desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Validação de nome e sobrenome.
- Validação de data de nascimento.
- Validação de email.
- Verificação de senha com mínimo de 8 caracteres.
- Confirmação de senha.
- Opção para mostrar e ocultar senha.
- Seleção de gênero.
- Mensagens de erro e confirmação.
- Layout responsivo para dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

Projeto desenvolvido para praticar desenvolvimento web, manipulação do DOM, eventos, validações e responsividade.
